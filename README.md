# 📰 Fake News Detection Using Machine Learning

A Machine Learning project that detects whether a news article is Real or Fake using Natural Language Processing (NLP).

## 🎯 Objective

To build a system that analyzes news text and predicts whether it is real or fake.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- NLP
- TF-IDF
- Logistic Regression
- Streamlit
- Joblib

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Text Preprocessing
4. Train-Test Split
5. TF-IDF Vectorization
6. Logistic Regression
7. Model Evaluation
8. Streamlit Prediction App

## 📊 Model Performance

- Accuracy: **98.98%**
- Precision: **0.99**
- Recall: **0.99**
- F1-Score: **0.99**
